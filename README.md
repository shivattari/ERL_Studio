# ERL_Studio

ERL Studio is an integrated development environment (IDE) for writing and executing programs in a modified version of OCR's Exam Reference Language (ERL).
It provides a custom code editor, real-time error detection, simple project management and an execution environment.

It includes its own compiler and virtual machine, allowing programs to be compiled into a custom bytecode and executed directly within the application.

## Features
### Code Editor
- Syntax highlighting: coloured keywords, data types, literals, subroutines and comments.
- Identifier highlighting: occurrences of the selected identifier are highlighted throughout the editor.
- Real-time error detection: errors and warnings are shown to the side of the incorrect code, with explanations shown on hover.
- Autosave: changes are automatically saved to the disk.
- Toggle themes: switch between a light or dark theme, with the preference saved between sessions.
- Line numbers.

### Project Management
- Create, rename and delete projects.
- Create and manage source files and resource files.
- Navigate projects using a file explorer in the sidebar.
- Reload workspace from disk (make changes in another editor and sync them over to execute).

### Compiler and Virtual Machine
- Tokeniser: converts source code into tokens and detects invalid syntax elements.
- Parser: constructs an abstract syntax tree (AST) representing the structure of the program.
- Sematic Analyser: performs type checking and other validation of the program.
- Bytecode Generator: translates the AST into a custom intermediate instruction set.
- Virtual Machine: executes the generated bytecode with a stack-based architecture.

### Supported Language Features
The language follows most conventions laid out by OCR in their J277 specification.
It is modified by introducing static type checking to the language, and a `main` method, thus bringing it closer to Java.

- Primitive data types: `int`, `float`, `boolean`, `char`, `String`.
- Variables, constants and global declarations.
- Arithmetic, comparison and logical operators.
- Conditional statements using `if`, `elseif` and `else`.
- Selection using `switch`, `case` and `default`.
- Iteration using `for`, `while` and `do...until` loops.
- One-dimensional and multidimensional arrays.
- User-defined functions and procedures, including recursion.
- String manipulation and type conversion.
- Console input and output.
- File reading and writing.
- Built-in mathematical and utility functions.

## Using ERL Studio
You can download a JAR executable of this program from the latest release.

This repository contains an _ExampleWorkspace_ directory, which has simple programs that demonstrate the different features of the language and errors it can detect.

1. Select a directory to use as your workspace.
2. Create a project with `File > New Project`.
3. Create a source file in your project with `File > New Source File`.
4. Write your code into the source file.
5. Click the run button in the toolbar to compile and execute the opened file.
6. Provide input to your program and read its output in the console.
